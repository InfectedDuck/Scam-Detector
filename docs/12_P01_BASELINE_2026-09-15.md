## Environment recovery

The virtual environment existed but could not start because its base interpreter, a per-user Python 3.12 installation, had been removed. Python 3.12.10 was restored as a user-level installation from the official Python installer. The existing `.venv` then worked without recreation.

Verified interpreter:

```text
Python 3.12.10
.venv\Scripts\python.exe
```

Reproducible setup from the repository root:

```powershell
py -3.12 --version
& .\.venv\Scripts\python.exe -m pip install -e '.[api,bot,eval,dev]'
Set-Location web
npm.cmd ci
```

`npm ci` needs access to the user-level npm cache on this Windows account. Python package installation found all declared dependencies already present and refreshed the editable `saqbol` package.
